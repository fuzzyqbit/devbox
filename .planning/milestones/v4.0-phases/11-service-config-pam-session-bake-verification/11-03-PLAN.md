  `/etc/xrdp/xorg.conf`. [CITED: xorgxrdp v0.10.5 xrdpdev/Makefile.am —
  `xrdpdevsysconfdir=$(sysconfdir)/X11/xrdp` + `dist_xrdpdevsysconf_DATA = xorg.conf`; the role
  configures `--sysconfdir=/etc` → `/etc/X11/xrdp/xorg.conf`.]
- sesman.ini.j2 line 33-35 passes `param=/usr/libexec/Xorg`, `param=-config`, `param=xrdp/xorg.conf`

  `/etc/X11` → `/etc/X11/xrdp/xorg.conf`. [CITED: Xorg(1) — "-config file ... will work for any file
  when the server is run as root ... or for files relative to a directory in the config search path";
  /etc/X11 is the config search root.]
- THEREFORE the correct present-and-asserted path is `/etc/X11/xrdp/xorg.conf`. The relative
  `xrdp/xorg.conf` in sesman.ini already resolves there; do NOT change sesman.ini.

SEMANAGE FCONTEXT IDEMPOTENCY (load-bearing): `semanage fcontext -a` ERRORS if the mapping already
exists ("ValueError: ... already defined"). Make it idempotent. Preferred: `community.general.sefcontext`
module (declarative, idempotent) IF the collection is available on the bake host. The repo already
relies on `community.general` elsewhere? — DO NOT assume; the SAFE, dependency-free form is an
`ansible.builtin.command` that checks first then adds:
  - query existing mappings: `semanage fcontext -l` (register, changed_when:false, failed_when:false)
  - add only when the target regex is NOT already in stdout (when: regex not in ...stdout), with
    `changed_when: true`; on the add command itself also set
    `failed_when: result.rc != 0 and 'already defined' not in result.stderr` as a second guard.
This double-guard (when-check + already-defined stderr tolerance) makes a re-bake safe.

executables labelled `xrdp_exec_t`. Mapping `/usr/local/sbin/xrdp` and `/usr/local/sbin/xrdp-sesman`
to `xrdp_exec_t` lets the enforcing-mode transition happen. Use ONE regex covering both binaries:

is a policy-absent condition — tolerate it with failed_when (see below) and let RDP-14 confirm under
enforcing; do NOT hard-fail the bake on a missing optional SELinux type. (AL2023 is permissive at
bake; the label only matters after hardening flips to enforcing — an RDP-14 concern.)
