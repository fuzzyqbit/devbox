# Requirements: devbox v3.0 — Jupyter + mise (Archived)

Scoped requirements for milestone v3.0 — SHIPPED 2026-06-02. Adds JupyterLab and the
`mise` version manager to the baked devbox AMI. Shipped as **loopback-only on-demand**
JupyterLab after a mid-milestone design pivot away from a password-protected systemd
service (see ROADMAP archive amendment).

## v3.0 Requirements (final status)

### Jupyter (JUP)

- [x] **JUP-01**: JupyterLab is installed in the baked AMI via the Ansible playbook — **Complete** (`/opt/jupyter` venv, pinned JupyterLab 4.5.7 + ipykernel 6.29.5, registered python3 kernel; installed via the `devtools` role after a post-execution refactor)
- [~] **JUP-02**: JupyterLab runs as a systemd service that starts on boot — **Superseded**: launched on demand via `./run jupyter` (no systemd service)
- [~] **JUP-03**: A per-build random Jupyter password generated + published to SSM SecureString — **Superseded**: loopback-only Jupyter needs no password
- [~] **JUP-04**: JupyterLab requires that password (no tokenless / open access) — **Superseded**: bound to `127.0.0.1`, reached only via SSM/IAM port-forward (the auth boundary)
- [~] **JUP-05**: Additional `:8888` ingress rule on `aws_security_group.devbox` — **Superseded**: nothing network-exposed; no SG rule needed
- [~] **JUP-06**: `./run secrets-show` reveals the Jupyter password — **Superseded**: no Jupyter password exists
- [x] **JUP-07**: Operator access to Jupyter surfaced in `./run` + docs — **Complete (amended)**: `./run jupyter` launcher + `./run status` hint + DEVELOPER-LIFECYCLE.md flow (manual `:8888` SSM port-forward; no always-on URL)
- [x] **JUP-08**: The `hardening` role remains the last role in `ansible/playbook.yml` — **Complete** (grep-gate 9 in pre-commit + CI; jupyter role inserted before hardening)

### mise (MISE)

- [x] **MISE-01**: The `mise` binary is installed in the baked AMI via the Ansible playbook — **Complete** (checksum-pinned jdx binary; installed via the `devops` role after a post-execution refactor)
- [x] **MISE-02**: `mise` shell activation configured for `ec2-user` interactive shells — **Complete** (`/etc/profile.d/mise.sh` → `eval "$(mise activate bash)"`; login shell required for SSM)
- [x] **MISE-03**: No committed `.mise.toml`; per-language Ansible layers (Python/Go/Rust/Java/Node) unchanged — **Complete** (grep-gate 10 in pre-commit + CI; language roles untouched)

## Outcomes / changed requirements

- **6 requirements superseded or amended by the loopback pivot** (JUP-02/03/04/05/06 superseded; JUP-07 amended). A loopback listener reached only via SSM/IAM removed the need for an app-layer password, TLS, a systemd service, and an SG ingress rule.
- **Role consolidation** post-execution: `mise` → `devops` role (commit ce777a3) and `jupyter` → `devtools` role (commit 12d8dc5). Requirement outcomes unchanged.
