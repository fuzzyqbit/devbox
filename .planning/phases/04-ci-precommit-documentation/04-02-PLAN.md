```yaml
      - id: tofu_fmt

  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v5.0.0
    hooks:
      - id: end-of-file-fixer
        stages: [pre-commit]
      - id: trailing-whitespace
        stages: [pre-commit]
      - id: check-merge-conflict
        stages: [pre-commit]
      - id: check-yaml
        stages: [pre-commit]
        exclude: |
          (?x)^(
            ansible/.*\.yml|
            \.gitleaks\.toml
          )$

  - repo: local
    hooks:
      - id: packer-fmt
        name: packer fmt -check
        entry: bash -c 'cd packer && packer fmt -check .'
        language: system
        pass_filenames: false
        files: ^packer/.*\.(pkr\.hcl|pkrvars\.hcl)$
        stages: [pre-commit]

      - id: grep-gates
        name: regression grep gates (Phase 3 invariants)
        entry: |
          bash -euo pipefail -c '
            # 1. Source AMI must not use most_recent=true (REP-04)
            ! grep -rE "most_recent[[:space:]]*=[[:space:]]*true" packer/ && \
            # 2. No hand-copied ami_id in terragrunt.hcl (REP-05)
            ! grep -E "^[[:space:]]*ami_id[[:space:]]*=[[:space:]]*\"ami-" terragrunt.hcl && \
            # 3. No raw <RESOLVED-VERSION> placeholder in packer/ (REP-04 follow-up)
            ! grep -- "<RESOLVED-VERSION>" packer/ && \
            # 4. ansible/requirements.yml uses ==X.Y.Z (REP-02) — comment-filtered to avoid self-invalidation
            ! (grep -vE "^[[:space:]]*#" ansible/requirements.yml | grep -E "^[[:space:]]*version:[[:space:]]*[^=]") && \
            # 5. terraform/.terraform.lock.hcl is tracked (REP-01)
            git ls-files terraform/.terraform.lock.hcl | grep -q . && \
            # 6. No re-add of lockfile to .gitignore (REP-01)
            ! grep -E "^[^#]*terraform/\\.terraform\\.lock\\.hcl" .gitignore
          '
        language: system
        pass_filenames: false
        stages: [pre-commit]
```

Notes on the grep-gates implementation:
- `entry:` uses YAML block scalar (`|`) so the multi-line bash is readable
- `bash -euo pipefail` ensures any assertion failure stops the hook immediately
- Each invariant is preceded by a comment naming the requirement ID for diffability
- Invariant #4 mirrors the comment-filtered form from plan 04-01's ci.yml (Critical Rules: grep gate hygiene — never `grep -c == 0` on unfiltered content)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
