## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| third-party-action -> CI runner | every `uses:` line pulls code into a runner with `${{ github.token }}` available |
| public commit -> CI workflow trigger | any push/PR (including from forks) triggers `ci.yml` — fork PRs run with read-only token (RESEARCH line 722) |
| .checkov.yaml -> Checkov action -> exit code | a malicious `skip-check` entry could silently suppress a real HIGH finding |
