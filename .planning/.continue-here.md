## Critical Anti-Patterns (do NOT repeat these)
- [HEREDOC-PR-BODY]: `gh pr create --body "$(cat <<'EOF'...)"` died on shell quoting (backticks/quotes in body) → ALWAYS write body to scratchpad file, use `--body-file` (advisory).
- [NO-CHANGEME-FALSE-POSITIVE]: `pre-commit run` fails repo-wide on `ansible/roles/secrets/tasks/generate.yml` `!= "changeme"` asserts — pre-existing, latent (hooks not installed in this clone). Don't chase it as a regression of your change; CI has no changeme grep (advisory).
- [CHAINED-COMMIT]: run `git commit` as its own Bash call — block-no-verify hook false-positives on chained commands (advisory, from memory).
- [LINT-FIX-NOTIFY]: `ansible-lint --fix` renames handlers without updating `notify:` refs — grep notify targets after every `--fix` (advisory, from memory).
- [GH-CHECKS-PENDING-0]: `gh pr checks` shows hung-but-running jobs as "pending 0" — check `.steps[]` via API for truth (advisory, 2026-07-13).
